# BIM Academy

Приложение для телефона (PWA) с материалами по BIM/ТИМ, Revit, Navisworks, AutoCAD и Civil 3D.

Открыть: https://big-arch.github.io/bim-learning-app/

## Что внутри

- **10 курсов, 85 уроков**: BIM и ТИМ, Revit, Navisworks, AutoCAD, Civil 3D, «Практикум», «BIM-менеджер», «Revit Server», «Английский для BIM» и «ПО для BIM».
- **Схемы-иллюстрации** прямо в уроках (LOD, IFC-обмен, цикл коллизий, диапазон вида Revit, коридор Civil 3D, архитектура Revit Server и другие) — векторные, работают офлайн, подстраиваются под тему и открываются крупно по нажатию с масштабом двумя пальцами.
- **538 вопросов** четырёх типов, минимум шесть на каждый урок: один ответ, несколько ответов, верно/неверно, ввод ответа. После ответа показывается правильный вариант и объяснение.
- **Мини-тест после каждого урока**, тест по курсу (10 вопросов) и экзамен (25 вопросов).
- **Собеседование**: 15 вопросов по всем направлениям за 10 минут, результат по каждому курсу и список уроков, которые стоит перечитать.
- **Игры**: «Найди пару» (термины, английский, горячие клавиши), «Блиц на минуту» (верно/неверно на скорость), «Собери порядок» (шаги инструкций из уроков). Рекорды и XP.
- **«Мои ошибки»** — интервальное повторение: ошибочный вопрос возвращается через 8 часов, затем через день, три дня, неделю.
- **Поиск** по урокам, терминам, вопросам и видео с подсветкой совпадений.
- **Глоссарий**: 221 термин с фильтром по курсам.
- **Видеоуроки**: 93 тематические подборки (открывают YouTube по теме) плюс возможность сохранить свои ссылки.
- **Шпаргалки горячих клавиш** Revit, AutoCAD, Civil 3D — собираются из уроков автоматически, плюс тренажёр на скорость.
- **Чек-листы для работы**: старт проекта, выдача модели, приёмка от смежника, запуск Revit Server — 86 пунктов, отметки хранятся отдельно по каждому проекту.
- **Справочник предупреждений Revit**: 40 разборов — что значит, чем грозит, как чинить.
- **Карточки терминов** с интервальным повторением.
- **Новости**: дайджест отрасли из 8 тем с выводом «что это значит для вас», хронология регулирования, каталог из 18 источников и необязательная живая RSS-лента.
- **Тренировка дня**: одна кнопка собирает 10 вопросов — ошибки к повтору, выцветающие темы, самый слабый курс и новое.
- **Освоение тем**: урок проходит уровни «пройдено → освоено → мастер». Освоенная тема через три недели «выцветает» и просит проверку из трёх вопросов.
- **Задания дня**: три задания каждый день (+10 XP), за пять полных дней недели — сундук с XP и заморозкой серии.
- **Серия с заморозкой**: заморозки выдаются за каждые 7 дней подряд и спасают серию при пропуске. Календарь занятий за 18 недель, сравнение с прошлой неделей и ежедневное напоминание через файл календаря.
- **Тренажёры**: диапазон вида Revit, допуск и зазор в проверке коллизий, шкала LOD — двигаешь ползунки, схема пересчитывается. Встроены в уроки и доступны из «Игр».
- **Кейсы с проекта**: 5 рабочих ситуаций по три решения с разбором последствий.
- **Траектории**: 5 маршрутов к роли через разные курсы и сертификат с именем (картинка PNG) за траекторию или курс.
- **Вопрос посреди урока** — проверка понимания до мини-теста.
- **Озвучка английского**: кнопка 🔊 у английских слов и фраз и словарь BIM English на 108 слов.
- **Компаньон на главной**: пять героев на выбор — инженер, кот-архитектор, BIM-бот, сова-наставник, бобр-строитель — в векторном или пиксельном стиле. Пьёт кофе утром, работает, читает и играет днём, спит ночью, подбадривает после неудачного теста и празднует выполненную цель дня. Иногда и по нажатию говорит фразы, с ростом звания получает значок, бабочку и корону. Выбор, стиль и выключение — в разделе «Ещё».
- **Прогресс**: XP и звания (Стажёр → BIM-эксперт), серия дней, цель на день, 15 достижений, закладки.
- **Тёмная и светлая тема**, офлайн-режим, экспорт и импорт прогресса файлом JSON.

## Синхронизация между устройствами

Раздел «Ещё» → «Синхронизация»: вход по почте с кодом из письма, без пароля.
Прогресс хранится в Supabase (проект «BIM Academy», таблица `progress`, одна
строка на пользователя с защитой RLS — каждый видит только свою). Изменения
уходят в облако через 2–3 секунды, открытые устройства получают их сразу.
Состояния не перезаписываются, а объединяются, поэтому сделанное офлайн не
теряется. Сброс прогресса на одном устройстве доходит до всех.

Настройки в панели Supabase, без которых вход работает не полностью:

- **Authentication → URL Configuration:** Site URL и Redirect URLs —
  `https://big-arch.github.io/bim-learning-app/`.
- **Authentication → Emails → Magic Link:** добавить в письмо код `{{ .Token }}`,
  иначе придёт только ссылка, а на iPhone она откроется в Safari, а не в
  установленном приложении.
- Встроенная почта Supabase отправляет письма только участникам вашей
  организации Supabase и с жёстким лимитом в час. Чтобы входили другие люди,
  подключите свой SMTP (Authentication → Emails → SMTP Settings).

## Курс «Практикум»

Отдельный курс из 14 уроков, собранный из реальных вопросов, которые задавали на проекте.
Каждый урок отвечает на один вопрос: что происходит, как правильно и почему.

| Урок | Вопрос |
| --- | --- |
| Рабочие наборы | По какому принципу делить и нужны ли именные наборы |
| Нумерация листов | Разбор схемы «альбом — часть — лист» |
| Файлы DWG | Связь или вставка и как удалить файл, которого не видно |
| Марки | Почему нельзя дублировать и чем задать одинаковую позицию |
| Семейства | Что значит «нестабильное» и что такое модель в контексте |
| Связи | Как подгрузить основной файл в фасад без круговой зависимости |
| ВОР | Имя файла: разделители, дата, версия, монтаж и демонтаж |
| Сжатие центральной модели | Что делает и когда запускать |
| СОД | Облачный диск, Revit Server и что можно сделать за неделю |
| Пересечения элементов | Во что обходятся двойные объёмы |
| Узлы | Легенда, чертёжный вид и база узлов между проектами |
| Настройка вида | Когда категории, а когда фильтры |
| Стены | Одна многослойная или несколько и куда вставлять проём |
| Демонтаж | Как специфицировать снятую дверь и закладку проёма |

## Курс «BIM-менеджер»

16 уроков по карте компетенций BIM-специалиста: аналитика и внедрение, техника и ПО,
координация, коммуникация, документы и стандарты, автоматизация.

Что разобрано: уровни зрелости BIM, GAP-анализ и дорожная карта, сценарии
использования, пилотный проект, EIR / BEP / BIM-стандарт, стандарты openBIM
(IFC, BCF, IDS, COBie, IDM, MVD, bSDD), различие LOD / LOI / LOIN, организация СОД
и резервного копирования, регламент координации, Dynamo и Revit API, стадии ЦИМ
в российской практике, карты процессов и бережливое производство, обучение команды,
экосистема расширений pyRevit и отдельно — RevitLookup.

**Про плагины pyRevit.** Уверенно описаны только документированные инструменты:
сам pyRevit, Revitron / Revitron UI, RevitLookup, Dynamo. Малоизвестные или локальные
расширения (CostEstimates, EF-Tools, pyRevit Autosave, pyArchitect, Quickly, P13, BMT
и подобные) урок не описывает по одному названию как факт — вместо выдуманных
описаний в нём показано, где смотреть автора и назначение конкретного расширения
внутри самого pyRevit.

## Курс «Revit Server»

6 уроков про совместную работу между офисами: от решения «нужен ли он вообще»
до разбора типовых отказов.

| Урок | О чём |
| --- | --- |
| Что такое Revit Server | Хост, ускорители, сравнение с общей папкой и облаком |
| Подготовка | Требования к серверу, канал между офисами, безопасность |
| Пошаговая установка | Хост, ускорители в филиалах, RSN.ini на клиентах, первая модель |
| Работа команды | Локальные копии, синхронизация, дисциплина, обрыв связи |
| Администрирование | Панель управления, блокировки, бэкапы, переход на новую версию |
| Типовые отказы | Симптом — причина — что делать и порядок диагностики |

**Важно про версии.** Revit Server выпускался для версий Revit по 2021
включительно; в более новых версиях Autodesk его не поставляет. Поэтому решение
о Revit Server всегда связано с решением о версии Revit — уточняйте для своей
версии и формы поставки. Точные пути, адреса панели и номера портов между
версиями отличаются: в уроках дана логика и порядок действий, конкретные строки
сверяйте с документацией своей версии.

## Курс «Английский для BIM»

6 уроков: интерфейс Revit по-английски, EIR/BEP/CDE в терминах ISO 19650, язык
координации и коллизий, деловая переписка, фразы для совещаний, строительная
лексика и «ложные друзья» (specification ≠ спецификация Revit, detail — узел,
phase — стадия). Словарь из 108 слов в `data/course-english.js` питает игры
«Найди пару» и «Блиц» — туда же можно дописывать свои слова.

На телефоне таблицы из трёх и более столбцов автоматически превращаются в
карточки, поэтому ничего не обрезается по ширине экрана.

## Курс «ПО для BIM»

8 уроков: как выбирать программу, типы лицензий, зарубежные и российские решения,
бесплатные инструменты и как собрать бюджет внедрения.

| Урок | О чём |
| --- | --- |
| Как выбирать ПО | Критерии выбора и стоимость владения за три года |
| Типы лицензий | Постоянная, подписка, аренда; именные и сетевые; как запросить КП |
| Autodesk | Revit, AutoCAD, Civil 3D, Navisworks, коллекция AEC |
| Другие зарубежные | Archicad, Allplan, Tekla, Solibri, MagiCAD, Rhino, Bluebeam |
| Российское: моделирование | Renga, nanoCAD BIM, Model Studio CS, Project Studio CS |
| Российское: сведение и СОД | CADLib, S-Info, Larix, Pilot-BIM, Vitro-CAD, TDMS, SIGNAL |
| Инфраструктура и бесплатное | Credo, IndorCAD, Robur, GeoniCS, Bonsai, FreeCAD, просмотрщики |
| Бюджет внедрения | Из чего складываются затраты и как показать отдачу |

**Про цены.** В уроках приведены ориентиры порядка величины на 2026 год — чтобы
понимать масштаб бюджета. Это не прайс: реальную стоимость подтверждает вендор
или его партнёр, российские вендоры часто считают предложение под проект, а
доступность лицензий отдельных зарубежных вендоров в России нужно проверять
отдельно по каждому.

## Установка на телефон

**iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран Домой».
**Android (Chrome):** открыть ссылку → меню → «Установить приложение».

После установки приложение работает без интернета — уроки, схемы и тесты хранятся на устройстве. Для видео нужен интернет: они открываются на YouTube.

## Локальный запуск

Из корня репозитория:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000/index.html

## Развёртывание на своём сервере

Приложение статическое, поэтому работает на любом веб-сервере. В каталоге
`deploy/` лежит готовый комплект:

```bash
echo "SITE_ADDRESS=bim.example.ru" > .env
docker compose up -d
```

Caddy сам получит сертификат Let's Encrypt. Есть и вариант без Docker — конфиг
для nginx с certbot, и скрипт выгрузки по rsync. Подробно: [deploy/README.md](deploy/README.md).

Проверка данных перед выгрузкой:

```bash
node deploy/check-content.cjs
```

## Как добавить свой урок

В нужный файл `data/course-*.js` добавить объект в массив `lessons`:

```js
{
  id: "revit-09",
  title: "Название урока",
  minutes: 10,
  level: "Средний",
  tags: ["тег"],
  goal: "Чему научится читатель.",
  blocks: [
    { type: "text", text: "Абзац текста." },
    { type: "list", title: "Список", items: ["пункт", "пункт"] },
    { type: "steps", title: "Порядок действий", items: ["шаг", "шаг"] },
    { type: "note", kind: "tip", title: "Совет", text: "..." },   // kind: tip | warn | rule
    { type: "table", title: "Таблица", head: ["A", "B"], rows: [["1", "2"]] },
    { type: "figure", figure: "revit-ui", caption: "Подпись" },     // ключ из data/figures.js
    { type: "key", items: ["главная мысль"] }
  ],
  terms: ["Семейство"],
  questions: [
    { type: "single", q: "Вопрос?", options: ["а", "б"], answer: 1, explain: "Почему." },
    { type: "multi", q: "Вопрос?", options: ["а", "б", "в"], answer: [0, 2], explain: "..." },
    { type: "bool", q: "Утверждение.", answer: true, explain: "..." },
    { type: "input", q: "Впишите ответ", answer: ["ifc"], explain: "..." }
  ]
}
```

Новые уроки, вопросы и термины подхватываются автоматически — прогресс и статистика пересчитываются сами.

Свои вопросы удобнее дописывать не в файл курса, а в `data/questions-extra.js`:
ключ — идентификатор урока, значение — массив вопросов в том же формате. Они
прирастают к уроку автоматически. Туда же логично складывать то, что спросили на
собеседовании или на планёрке.

## Про содержание уроков

Материал написан как учебная база: понятия, порядок работы, типовые ошибки и то, что реально спрашивают на проектах. Нормативные ссылки (ПП РФ № 331, СП 333.1325800, ГОСТ Р 10.0.02 и другие) даны для ориентира — перед выдачей документации сверяйтесь с действующей редакцией и требованиями заказчика.
